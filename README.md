# Practice 01: Pandas and Course Allocation

Учебный проект по анализу табличных данных с помощью **pandas** и визуализации с помощью **matplotlib/seaborn**.
Во второй части проекта реализован алгоритм распределения студентов по элективным курсам на основе приоритетов, перцентиля и ограничений по вместимости курсов.

## О проекте

Проект состоит из двух частей:

1. **Анализ табличных данных**
   - загрузка и первичное исследование данных;
   - обработка пропусков;
   - анализ предпочтений студентов;
   - поиск повторяющихся выборов;
   - сравнение курсов между наборами студентов;
   - построение визуализации.
2. **Распределение студентов по курсам**
   - вычисление количества необходимых курсов для каждого студента;
   - распределение по осенним курсам;
   - распределение по весенним курсам;
   - учет ограничений на вместимость;
   - проведение отбора по волнам в соответствии с приоритетами студентов.

## Используемые технологии

- Python
- pandas
- numpy
- matplotlib
- seaborn
- Jupyter Notebook
